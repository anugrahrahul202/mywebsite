# 🌸 A Little Reason to Smile 💗

*A tiny pastel storybook made to bring a smile to someone's face.*

**A Little Reason to Smile** is a cute, interactive, romantic website created as a little digital surprise for someone special. It features pastel colors, sweet messages, adorable cats, a virtual bouquet, background music, and interactive animations.

The idea is simple: sometimes, a small gesture is enough to make someone's day a little brighter. ♡

## ✨ Features

- 🌙 **Beautiful Design** — A dreamy, pastel-pink storybook theme.
- 💌 **Interactive Love Letter** — Open an envelope to reveal a heartfelt message.
- 🐱 **Cute Cat Moments** — Interactive cat animations and sweet compliments.
- 💐 **Virtual Flower Bouquet** — A special bouquet linked from the website.
- 🎀 **Cheer Squad** — Gentle reminders and positive messages.
- 💭 **A Heartfelt Question** — A thoughtful message that encourages honest communication without pressure.
- 🌷 **Blooming Flower Animation** — Watch a little flower bloom with a click.
- 🎁 **Surprise Gift** — Open a virtual gift to reveal a final message.
- 🎵 **Background Music** — Plays *Perfect* when the browser allows autoplay, with a button to start it manually.
- 💖 **Floating Hearts and Sparkles** — Small animations throughout the experience.
- 📱 **Responsive Layout** — Designed to work on desktop and mobile screens.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Emoji and CSS animations
- MP3 audio for background music

No frameworks, dependencies, or build tools are required.

## 📂 Project Structure

Keep these files together in the same folder:

```text
a-little-reason-to-smile/
├── index.html
├── Perfect.mp3
└── README.md
```

- `index.html` — The complete website, including its styling and JavaScript.
- `Perfect.mp3` — The background music file.
- `README.md` — Project documentation.

**Important:** The music file must be named exactly `Perfect.mp3` and placed beside `index.html` for the background music to work.

## 🚀 Run the Website Locally

1. Download or clone this repository.
2. Make sure `index.html` and `Perfect.mp3` are in the same folder.
3. Open `index.html` in your web browser.
4. Explore the pages using the navigation buttons.
5. If the music does not start automatically, click **"♫ Play our song"**.

Some browsers block autoplay until the user interacts with the page. This is normal.

## 🌐 Publish with GitHub Pages

You can host this website for free using GitHub Pages.

1. Create a repository on GitHub.
2. Upload `index.html`, `Perfect.mp3`, and `README.md`.
3. Open your repository's **Settings**.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder.
7. Click **Save**.
8. Wait for GitHub Pages to publish the website.

Your website will be available at an address similar to:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your actual GitHub username and repository name.

## 🎵 About the Background Music

The website references a local audio file named `Perfect.mp3`.

- Keep the file in the same directory as `index.html`.
- Make sure the filename and capitalization match exactly.
- Browsers may require a click before playing audio.
- Only upload music you have permission to distribute publicly. If you don't have permission to publish the song, consider keeping the audio file private or using music you are licensed to share.

## 🎨 Customization

You can personalize the experience by editing `index.html`.

- **Messages:** Change the text inside the HTML sections.
- **Colors:** Adjust the CSS color values.
- **Bouquet:** Replace the bouquet link with your own.
- **Music:** Change the audio filename in the HTML and use a matching audio file.
- **Animations:** Customize the CSS animations and JavaScript interactions.
